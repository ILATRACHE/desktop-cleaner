# desktop-cleaner
Desktop Cleaner is a Python application that automatically organizes files by sorting them into folders based on their extensions. It scans a selected directory, creates category folders when needed, and moves files to their proper locations. The goal is to keep desktops clean, organized, and easy to manage while saving time.

## Guide
1. Open a terminal.
2. Run the program : cleanfunction.py.
3. Enter the path of the folder you want to organize.
4. Press Enter.
5. The program scans the folder and sorts files into categories based on their extensions.
6. A summary is displayed showing the number of files moved.
